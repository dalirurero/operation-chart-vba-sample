# 公開用簡易仕様書

## 1. 目的

外部Excelデータを取り込み、参照CD生成、エリアマスタ照合、作業割当表作成、個人別指示書・帳票印刷までを一連で処理するVBAサンプルである。

## 2. 動作環境

- Windows
- Excel 2019 / 2024 デスクトップ版
- マクロ有効ブック
- 外部ファイルはマクロブックと同一フォルダに配置

## 3. シート構成

| シート | 役割 |
|---|---|
| MF | 処理基準日の確認、取込実行 |
| 作業編成画面 | 当日分の作業割当 |
| 作業編成画面A | 次回予定分の作業割当 |
| 指示書 | 作業者別指示書 |
| エリアデータ | 参照CDと標準時間のマスタ |
| 入荷データ | 当日分取込結果 |
| 入荷データA | 次回予定分取込結果 |

## 4. 外部ファイル

### SEND_SAMPLE.xlsx

- 対象シート: `Sheet1`
- A:N列を使用
- 当日分データ
- N列が空白の場合は入替対象

### SEND3_SAMPLE.xlsx

- 対象シート: `Sheet1`
- A:M列を使用
- 次回予定分データ

公開サンプルでは `.xlsx` を使用する。業務ロジックは外部ファイル形式以外、実装版と同じ考え方を維持する。

## 5. 参照CD生成

次の規則で生成する。

```text
参照CD = 数値化した棚1 × 100 + 数値化した棚2 + エリアコード
```

例: 棚1=`01`、棚2=`02`、エリア=`1B` の場合は `1021B`。

参照CD生成後、重複を除外して昇順に並べ、エリアデータに登録されているか照合する。

## 6. 日付判定

- MFのD5を処理基準日とする。
- D6が空白または0の場合は当日。
- D6=-1は前日、D6=1は翌日。
- 当日分は処理基準日と照合する。
- 次回予定分は次回納品予定日と照合する。
- 水曜日は納品なし。
- 日付が想定より新しい場合は確認後に続行可能。
- 古いデータは対象側をデータなしとして扱う。

## 7. 作業編成画面

- 商品開始行は5行目。
- 5行目をテンプレートとして使用する。
- 参照CDはA列。
- I列で担当者を選択する。
- K5=`残りの品出し`、K6=`前倒し`。
- K7以下に店舗の作業者全員を登録する。
- サンプルでは `作業者A`、`作業者B` を使用する。
- A1、E2、G2はシート数式で表示する。
- VBAから結合セルE2:F2は操作しない。

## 8. 指示書

- 作業者ごとに1商品1行で作成する。
- 3行目をテンプレートとして使用する。
- C・D・F列の数式を商品件数分展開する。
- 商品数が多い場合は3行単位で可変範囲を拡張する。

## 9. 保護

起動時に次のシートを保護する。

- MF
- 作業編成画面
- 作業編成画面A
- 指示書
- エリアデータ

`入荷データ`、`入荷データA`はVBA更新対象のため保護対象外とする。

処理開始時の保護状態を記録し、終了時に元の状態へ戻す。

## 10. エラー処理

主な中止条件:

- 必須シートが存在しない
- 外部データに複数の納品日がある
- 参照CDを生成できない
- エリアデータに未登録の参照CDがある
- 作業者名が重複している
- I列の氏名が作業者一覧に存在しない

エラー時は可能な限り既存帳票を残した状態で処理を終了する。

## 11. 公開版固有事項

- 実データは使用しない。
- 作業者は `作業者A`、`作業者B`。
- 店舗コード、棚、エリア、数量等はダミーデータ。
- シート名は日本語のまま維持する。
- VBAソースは `src/` に分離する。
